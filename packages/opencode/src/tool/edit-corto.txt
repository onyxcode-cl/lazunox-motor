Performs exact string replacements in files.

- You must Read the file at least once in the conversation before editing; the edit errors otherwise.
- When copying text from Read output, keep the exact indentation as it appears AFTER the line-number prefix (`1: `, number + colon + space). Never include the prefix in `oldString` or `newString`.
- It FAILS if `oldString` is not found or is found several times: give more surrounding context to make it unique, or use `replaceAll` to change every instance (e.g. renaming a variable).
